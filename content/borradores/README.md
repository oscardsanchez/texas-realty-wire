# Borradores

Notas generadas por el proceso de actualización automática (ver `docs/actualizaciones-automaticas.md`)
que todavía **no han sido revisadas**. No se publican en el sitio — `getAllNotas()` solo lee
`content/notas/`.

Para publicar un borrador: revísalo, y si está listo, muévelo a `content/notas/` (mismo
nombre de archivo) y haz commit. Si no sirve, bórralo.
